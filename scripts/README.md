# scripts

이 디렉터리에는 **저장소 공통 인코딩 검증**만 둔다.

| 파일 | 역할 |
|------|------|
| `check_encoding.py` | UTF-8 디코드 가능 여부, UTF-8 BOM, 자주 보이는 깨진 한글(모지바케) 마커 검사 |

실행:

```bash
npm run check:encoding
```

**게이트**: 위 검사가 실패하면 **해당 작업(변경 묶음) 전체를 실패로 본다.** 인코딩을 고치겠다고 `scripts/`에 일괄 치환·복구용 스크립트를 추가하지 않는다. 통과할 때까지 변경을 되돌리거나 폐기한다.
