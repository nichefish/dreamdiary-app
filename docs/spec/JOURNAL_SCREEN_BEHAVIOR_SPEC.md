# 저널 화면 동작 기획서

## 1. 문서 범위

이 문서는 저널 화면 전체에서 사용자가 무엇을 보고, 각 조작이 화면상에서 어떻게 이어지는지를 정리한다.

대상 화면:

- 저널 월간 화면
- 저널 주간 화면
- 저널 일간 화면
- 저널 캘린더 화면
- 캘린더나 목록에서 여는 일자 상세 모달
- 일기/꿈 엔트리 검색 화면
- 메타 화면

대상 요소:

- 일자
- 챕터
- 일기
- 노트
- 꿈
- 해석
- 댓글
- 관련글
- 태그
- 메타
- TODO
- 검색과 필터
- 라이프사이클과 접힘 상태

---

## 2. 저널 화면의 큰 구조

### 2.1 화면 구획

저널 화면은 크게 네 영역으로 읽힌다.

1. 상단 도구 영역
2. 좌측 사이드 영역
3. 태그/메타 요약 영역
4. 날짜별 저널 본문 영역

상단 도구 영역에는 뷰 전환, 고급 필터, 등록 액션, 검색으로 이어지는 진입점이 놓인다.

좌측 사이드 영역에는 기간 이동, 주간 네비게이션, 현재 위치 고정, TODO, 보기 필터가 모인다.

본문 영역에는 날짜 카드가 반복되고, 날짜 카드 안에 챕터와 엔트리가 배치된다.

---

## 3. 기간 이동과 화면 전환

### 3.1 년도와 월 이동

사이드바에는 년도와 월 선택이 있다.

화면 흐름:

1. 사용자가 년도를 고른다.
2. 월 선택이 초기화된다.
3. 월을 고르면 해당 년월의 저널 목록이 다시 그려진다.

월 이동 버튼을 누르면:

- 왼쪽 버튼은 이전 월
- 오른쪽 버튼은 다음 월

로 이동한다.

`TODAY` 버튼을 누르면 현재 날짜가 속한 월로 돌아간다.

### 3.2 주간 이동

주간 화면에서는 사이드바에 한 주 범위가 표시된다.

화면 흐름:

1. 현재 기준일이 속한 주의 시작일과 종료일이 보인다.
2. 월~일 버튼이 한 줄로 표시된다.
3. 기록이 있는 날짜만 선택 가능하게 보인다.
4. 날짜 버튼을 누르면 그 날짜가 기준이 된 주간 화면으로 이동한다.

주간 이동 버튼:

- 왼쪽 버튼: 이전 주
- 오른쪽 버튼: 다음 주
- `TODAY`: 오늘이 속한 주

### 3.3 Pinpoint

사이드바의 `Pinpoint` 영역은 현재 보고 있는 년월을 임시 기준점처럼 다룬다.

화면 흐름:

1. 사용자가 책갈피 버튼을 누른다.
2. 현재 년월이 고정 텍스트로 표시된다.
3. 이후 다른 기간으로 이동해도, 되돌리기 버튼으로 고정한 위치로 돌아간다.

### 3.4 상단 뷰 전환

저널 상단 탭이나 전환 액션을 통해 화면은 다음 보기로 오간다.

- 월간 목록
- 주간 목록
- 캘린더
- 메타

화면 전환 시 현재 필터와 기준 기간은 가능한 한 이어져 보인다.

## 4. 상단 도구 영역

### 4.1 고급 필터 열기

상단의 `고급필터` 버튼을 누르면 접혀 있던 추가 필터 영역이 열리고 닫힌다.

### 4.2 일정 등록 액션

상단 도구에는 일정 등록 액션이 함께 놓인다.

- 일정 등록
- 개인용 일정 등록

저널 목록을 보던 맥락에서 바로 일정 등록 흐름으로 이동할 수 있다.

### 4.3 태그 카테고리 동기화

태그 카테고리 동기화 버튼을 누르면 화면에서 사용하는 태그 분류 정보가 갱신되는 흐름으로 이어진다.

### 4.4 저널 일자 등록

상단 등록 버튼을 누르면 저널 일자 등록 흐름으로 들어간다.

---

## 5. 사이드 필터

### 5.1 태그클라우드 표시

`TAGCLOUD` 토글을 통해 태그 요약 영역을 보이거나 숨긴다.

태그클라우드가 켜져 있으면:

- 일자 태그 요약
- 일기 태그 요약
- 꿈 태그 요약

이 현재 조회 조건에 맞춰 표시된다.

### 5.2 일기 보기 토글

`DIARIES` 토글을 끄면 일기 챕터와 일기 엔트리 영역이 화면에서 빠진다.

다시 켜면 같은 조건의 일기 영역이 되살아난다.

### 5.3 꿈 보기 토글

`DREAMS` 토글을 끄면 꿈 엔트리 영역이 숨겨진다.

다시 켜면 꿈 목록이 되살아난다.

꿈이 존재하지만 숨김 상태라면, 본문에는 꿈이 숨겨져 있다는 안내 배지가 나타난다.

### 5.4 챕터 카테고리 필터

일기 필터 영역에는 챕터 카테고리 다중 선택이 있다.

화면 흐름:

1. 사용자가 하나 이상의 챕터 카테고리를 선택한다.
2. 본문에는 해당 카테고리 기준으로 걸러진 챕터만 남는다.
3. 숨겨진 카테고리가 있으면 일자 카드 안에 `CHAPTER FILTER` 안내와 숨김 카테고리 배지가 함께 보인다.

### 5.5 키워드 필터

사이드바에는:

- 일기 키워드 입력
- 꿈 키워드 입력

이 각각 있다.

입력 후 `Enter`를 누르면 현재 목록에 키워드 필터가 적용된다.

### 5.6 확장 필터 영역

고급 필터 아코디언을 열면 추가 조건을 배치할 수 있는 영역이 펼쳐진다.

## 6. 태그 요약 영역

### 6.1 일자 태그 요약

일자 태그 영역에는 현재 기간에 등장한 저널 일자 태그가 나열된다.

각 태그에는:

- 카테고리
- 태그명
- 사용 건수

가 함께 표시될 수 있다.

### 6.2 일기 태그 요약

일기 태그 영역에는 현재 조회 조건의 일기 태그들이 나열된다.

태그를 누르면 태그 컨텍스트 흐름이 열린다.

그 안에서:

- 해당 태그의 일기 검색으로 이어가거나
- 태그 프로필을 다루는 흐름으로 들어간다.

### 6.3 꿈 태그 요약

꿈 태그 영역도 같은 방식으로 동작한다.

태그를 누르면:

- 해당 태그를 가진 꿈 검색으로 이어가거나
- 태그 프로필을 다루는 흐름으로 이어진다.

### 6.4 태그 전체 목록 모달

전체 태그 목록을 여는 흐름에서는 태그들이 모달 안에 넓게 펼쳐진다.

모달 안에서는:

- 전체 카테고리
- 카테고리별 토글

을 이용해 태그 표시 범위를 바꿔 볼 수 있다.

카테고리를 켜고 끄면 해당 카테고리 태그들이 모달 목록에서 함께 나타나거나 빠진다.

---

## 7. 일자 카드

### 7.1 일자 헤더

각 일자 카드는 다음 정보를 함께 보여준다.

- 날짜
- 요일
- 대략일/미상일 같은 날짜 정밀도 배지
- 날씨
- 공휴일명

공휴일은 날짜 표현이 별도로 강조되어 보인다.

### 7.2 일자 헤더 액션

일자 카드 헤더에는 다음 조작이 놓인다.

- 챕터 등록
- 꿈 등록
- 더보기 메뉴
- 메타 요약 버튼

### 7.3 챕터 등록

`챕터 등록`을 누르면 해당 날짜를 기준으로 챕터 등록 모달이 열린다.

### 7.4 꿈 등록

`꿈 등록`을 누르면 해당 날짜 기준의 꿈 등록 모달이 열린다.

### 7.5 일자 더보기 메뉴

일자 더보기 메뉴에서는 다음 흐름으로 이어진다.

- 해당 일자를 새 창의 일간 화면으로 열기
- 해당 일자가 포함된 주간 보기로 이동
- 일자 수정 모달 열기
- 일자 접힘 상태 변경
- 일자 삭제

### 7.6 메타 요약 버튼

일자에 메타가 있으면 막대 차트 아이콘이 보인다.

버튼에 마우스를 올리면:

- 메타 카테고리
- 메타 이름
- 값과 단위

가 요약 형태로 뜬다.

## 8. 일자 태그와 태그 상세

### 8.1 일자 카드의 태그

일자 카드 아래에는 해당 날짜에 붙은 태그가 보인다.

태그는:

- `#`
- 카테고리
- 태그명

의 형태로 표시된다.

### 8.2 일자 태그 클릭

일자 태그를 누르면 태그 컨텍스트 흐름이 열린다.

여기서 사용자는:

- 해당 태그가 붙은 저널 일자 목록을 열거나
- 해당 태그의 프로필을 편집하는 흐름으로 간다.

### 8.3 일자 태그 상세 모달

태그 상세를 열면 모달이 나타난다.

모달에는:

- 태그명
- 해당 태그가 붙은 일자 수
- 연도 선택
- 해당 일자 카드 목록

이 함께 보인다.

연도를 바꾸면 같은 태그의 다른 연도 기록으로 목록이 바뀐다.

주간 맥락에서 연 상세은 주간 기준 결과를 보여준다.

---

## 9. 챕터

### 9.1 챕터 헤더

챕터는 다음 정보를 함께 보여준다.

- 챕터 타입
- 챕터 카테고리명
- 챕터 카테고리 코드
- 타입 아이콘

카테고리가 있는 챕터는 타입 라벨 뒤에 `:카테고리명 카테고리코드` 형식으로 표시한다.

- 예: `일기:요약 SUMMARY`
- 예: `노트:리뷰 REVIEW`
- 타입 라벨과 콜론 사이, 콜론과 카테고리명 사이에는 추가 공백을 두지 않는다.
- 카테고리명은 헤더 크기를 상속하고 `#287D94` 색으로 표시한다.
- 카테고리코드는 회색 보조 텍스트(`text-muted fs-8 me-1`)로 표시한다.
- 카테고리명과 카테고리코드는 DOM 사이 공백으로만 구분한다.

챕터 타입에 따라 아이콘과 라벨이 달라진다.

- 일기 챕터
- 노트 챕터
- 꿈 챕터

### 9.2 챕터 액션

챕터 헤더에서는 다음 조작이 가능하다.

- 해당 챕터 안에 엔트리 등록
- 챕터 내용 복사
- 챕터 TXT 내보내기
- 챕터 수정
- 챕터 접기/펼치기
- 챕터 삭제

### 9.3 챕터 접기

챕터를 접으면 챕터 안의 엔트리 목록은 접힌 상태로 바뀐다.

대신 챕터 하단에는 그 챕터의 태그 요약이 보인다.

이 요약 태그를 누르면 해당 태그 흐름으로 이어진다.

### 9.4 SUMMARY 챕터

`SUMMARY` 챕터도 다른 챕터와 같은 방식으로 표시되고 조작된다.

해당 챕터 안에서 등록을 시작하면 그 챕터가 초기 선택값이 된다.

## 10. 엔트리 행

### 10.1 공통 구조

일기와 꿈 엔트리는 대체로 다음 구조로 보인다.

- 좌측 순번
- 접기/펼치기 버튼
- 본문 영역
- 댓글 버튼
- 복사 버튼
- 더보기 메뉴

### 10.2 꿈 엔트리의 추가 표시

꿈 엔트리에는 별도 상태 배지가 붙을 수 있다.

- 악몽
- 환각/현시
- 타인의 꿈 여부와 꿈꾼 사람 표시

꿈 제목이 있으면 꿈 상태 배지 옆에 제목도 함께 보인다.

### 10.3 엔트리 본문

본문 영역에는 마크다운 렌더링 결과가 표시된다.

필요할 때는 작은 펼침 버튼을 눌러 접혀 있던 태그 강조 본문을 더 넓게 읽는다.

### 10.4 엔트리 태그

본문 아래에는 엔트리에 붙은 태그가 표시된다.

태그를 누르면 태그 컨텍스트 흐름이 열린다.

사용자는:

- 같은 태그의 일기/꿈 검색으로 이어가거나
- 태그 프로필 흐름으로 들어갈 수 있다.

### 10.5 관련글

관련글이 연결된 엔트리에는 별도 관련글 박스가 나타난다.

박스에는:

- 대상 콘텐츠 타입
- 대상 번호
- 제목
- 연결 사유

가 표시된다.

사용자는:

- 관련글 열기
- 관련글 연결 삭제

를 할 수 있다.

### 10.6 댓글

댓글이 있는 엔트리는 본문 아래에 댓글 목록이 이어진다.

각 댓글은:

- 본문
- 수정 버튼
- 삭제 버튼

으로 보인다.

엔트리 행의 댓글 버튼을 누르면 댓글 등록 모달이 열린다.

### 10.7 해석

엔트리에 해석이 붙어 있으면 엔트리 아래에 해석 목록이 이어서 나타난다.

엔트리 더보기 메뉴에서 해석 등록을 누르면 해당 엔트리를 참조하는 해석 등록 모달이 열린다.

## 11. 엔트리 등록

### 11.1 챕터 안에서 일기 등록

사용자가 특정 챕터 안의 일기 등록 버튼을 누른다.

화면 흐름:

1. 등록 모달이 열린다.
2. 모달 상단에 현재 날짜가 표시된다.
3. 챕터 선택 필드에는 방금 사용자가 눌렀던 챕터가 선택되어 있다.
4. 사용자가 제목과 본문을 입력한다.
5. 저장한다.
6. 모달이 닫히고, 새 일기가 해당 챕터 아래에 나타난다.

### 11.2 등록 중 챕터 변경

등록 모달이 열린 상태에서 사용자는 챕터 선택값을 바꿀 수 있다.

화면 흐름:

1. 챕터 A에서 등록을 시작한다.
2. 모달은 챕터 A가 선택된 상태로 열린다.
3. 사용자가 챕터 선택을 B로 바꾼다.
4. 저장한다.
5. 새 일기는 챕터 B 아래에 나타난다.

### 11.3 노트 등록

노트 등록도 같은 방식으로 전개된다.

1. 특정 챕터에서 노트 등록을 누른다.
2. 등록 모달이 열린다.
3. 그 챕터가 선택되어 있다.
4. 저장하면 새 노트가 해당 챕터 아래에 나타난다.

### 11.4 꿈 등록

꿈 등록은 꿈 전용 흐름으로 열린다.

1. 꿈 등록을 누른다.
2. 꿈 등록 모달이 열린다.
3. 꿈 제목과 내용을 입력한다.
4. 저장한다.
5. 꿈 엔트리가 꿈 챕터 영역에 나타난다.

## 12. 엔트리 수정과 이동

### 12.1 수정 진입

기존 엔트리에서 수정 버튼을 누르면 수정 모달이 열린다.

모달에는:

- 기존 제목
- 기존 본문
- 현재 챕터
- 정렬 순서 등 수정 가능한 값

이 채워져 보인다.

### 12.2 내용만 수정

챕터를 바꾸지 않고 제목이나 본문만 고치면:

1. 저장 후 모달이 닫힌다.
2. 같은 챕터 안의 같은 엔트리가 수정된 내용으로 갱신된다.

### 12.3 챕터를 바꾸며 수정

수정 모달에서 챕터를 바꾸고 저장하면:

1. 기존 챕터 목록에서 엔트리가 빠진다.
2. 새 챕터 목록에 같은 엔트리가 나타난다.

사용자 눈에는 엔트리가 챕터 사이를 이동한 것으로 보인다.

### 12.4 꿈 수정

꿈 엔트리를 수정하면:

- 같은 꿈 챕터 아래에서 내용이 갱신된다.
- 꿈 제목과 꿈 본문, 꿈 전용 상태가 함께 반영된다.

---

## 13. 라이프사이클과 상태

### 13.1 라이프사이클

엔트리의 라이프사이클은 세 가지다.

- `OPEN`
- `PENDING`
- `RESOLVED`

더보기 메뉴의 라이프사이클 영역에서 하나를 선택한다.

### 13.2 OPEN

`OPEN`은 진행 중인 기록으로 보인다.

기존 접힘 여부는 그대로 둔 채 라이프사이클 표시만 `OPEN`으로 바뀐다.

### 13.3 PENDING

`PENDING`은 보류 상태로 보인다.

본문 접힘 여부와는 별개로 상태 표시만 바뀐다.

### 13.4 RESOLVED

`RESOLVED`를 선택하는 순간:

1. 라이프사이클 표시가 완료 상태로 바뀐다.
2. 순번 표시는 완료 강조를 받는다.
3. 본문이 자동으로 접힌다.
4. 접힘 버튼과 상태 표시도 접힌 상태에 맞춰 바뀐다.

사용자에게는 “작성 완료 처리와 동시에 글이 정리되어 접힌다”는 흐름으로 보인다.

### 13.5 일반 상태 토글

엔트리 더보기 메뉴에서는 다음 상태를 켜고 끌 수 있다.

- 중요
- 참조
- 접힘

꿈 엔트리에서는 여기에:

- 악몽
- 환각/현시

가 더해진다.

상태를 바꾸면 본문 강조, 배지, 접힘 표시가 즉시 달라진다.

### 13.6 완료된 글 다시 펼치기

`RESOLVED`로 접힌 엔트리를 다시 펼치면:

- 완료 상태는 계속 보인다.
- 본문만 다시 열린다.

## 14. 엔트리 더보기 메뉴

엔트리의 더보기 메뉴는 다음 흐름을 모아 둔다.

- 해석 등록
- 수정
- 히스토리 보기
- 관련글 추가
- 라이프사이클 변경
- 상태 토글
- 삭제

검색 화면의 엔트리에서는 추가로:

- 해당 일자를 새 창으로 열기

흐름이 제공된다.

히스토리가 없는 경우 히스토리 메뉴는 비활성 상태로 보인다.

## 15. 일자 상세 모달

### 15.1 상세 모달 진입

일자 상세를 열면 해당 날짜의 정보를 모달 안에 압축해서 보여준다.

모달 상단에는:

- 날짜
- 요일
- 날짜 정밀도
- 날씨
- 일자 태그

가 보인다.

### 15.2 상세 모달의 본문

상세 모달 안에는:

- 일기 엔트리
- 꿈 엔트리
- 타인 꿈 엔트리

가 이어서 나타난다.

각 항목은:

- 댓글 등록
- 복사
- 더보기 메뉴

를 그대로 제공한다.

## 16. 검색

### 16.1 본문 화면의 빠른 검색

저널 본문 상단에는:

- 일기 키워드 검색 입력
- 꿈 키워드 검색 입력

이 있다.

검색 버튼을 누르면 해당 타입의 엔트리 검색 팝업으로 이어진다. Vue 통합 후에도 이 검색은 현재 목록을 필터링하는 동작이 아니라 `/vue-app/journal/entry/search` 새 창 route로 열린다. 이 팝업에는 기본 메뉴와 저널 사이드바를 표시하지 않는다.

### 16.2 엔트리 검색 화면

엔트리 검색 화면은 일기와 꿈을 각각 검색하는 전용 화면이다. route query는 `type=DIARY|DREAM`, `tagIds`, `tagName`, `searchKeywords`를 기준으로 복원할 수 있어야 한다.

상단에는:

- 초기화
- 정렬 전환
- 검색
- 결과 복사
- TXT 내보내기

버튼이 있다.

### 16.3 검색 조건

고급 검색 영역에서 사용자는:

- 키워드를 추가하고
- 태그를 선택하고
- 검색 조건을 누적한다.

선택된 키워드와 태그는 상단 배지 영역에 표시된다.

### 16.4 검색 실행

검색을 실행하면:

1. 입력한 키워드와 태그 조합으로 결과를 조회한다.
2. 결과는 월별 구분선을 기준으로 묶여 나타난다.
3. 각 결과 행은 일반 엔트리 행과 같은 방식으로 읽고 조작할 수 있다.

검색 조건이 하나도 없으면 검색 결과 영역에는 안내 메시지가 뜬다.

### 16.5 검색 결과 액션

검색 결과 상단에서:

- 현재 결과 전체 복사
- TXT 내보내기

를 실행할 수 있다.

결과 개별 행에서는:

- 댓글 등록
- 복사
- 해석 등록
- 관련글 추가
- 라이프사이클 변경
- 상태 변경

흐름을 그대로 사용할 수 있다.

## 17. 메타 화면

### 17.1 메타 헤더 목록

메타 화면에서는 상단에 메타 이름 목록이 태그처럼 표시된다.

사용자가 메타 이름을 누르면:

1. 선택된 메타가 현재 선택 항목으로 표시된다.
2. 선택 메타의 보조 액션 영역이 함께 나타난다.

### 17.2 선택된 메타 스트립

선택된 메타는:

- 카테고리
- 이름

이 강조되어 보인다.

옆의 차트 버튼을 누르면 해당 메타가 등장한 일자 목록 모달이 열린다.

### 17.3 메타 모달

메타 모달에는:

- 연도 선택
- 월별 묶음
- 해당 메타가 기록된 일자와 값
- 일자 새 창 열기
- 그 일자에 붙은 태그

가 함께 표시된다.

연도를 바꾸면 같은 메타의 다른 연도 목록으로 갱신된다.

일자 태그를 누르면 다시 일자 태그 흐름으로 이어진다.

## 19. 저장 이후 다시 보이는 모습

### 19.1 등록 직후

- 새 챕터는 해당 일자 아래에 나타난다.
- 새 일기나 노트는 선택한 챕터 아래에 나타난다.
- 새 꿈은 꿈 영역에 나타난다.

### 19.2 수정 직후

- 내용만 바꾼 엔트리는 같은 위치에서 본문만 갱신된다.
- 챕터를 바꾼 엔트리는 기존 챕터에서 빠지고 새 챕터에 나타난다.

### 19.3 상태 변경 직후

- 상태 배지와 강조가 즉시 바뀐다.
- `RESOLVED`는 완료 표시와 자동 접힘이 동시에 보인다.

### 19.4 다시 같은 화면을 열었을 때

같은 일자나 같은 검색 결과를 다시 보면:

- 저장한 챕터 위치
- 수정된 본문
- 붙어 있는 태그
- 라이프사이클
- 접힘 상태

이 마지막 조작 결과를 기준으로 다시 보인다.
