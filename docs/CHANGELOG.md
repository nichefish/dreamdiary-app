### 2026-08-26 | v0.29.0
- 신규 기능
  - **저널 스레드 본문 이력**: 스레드 본문의 변경 이력을 조회·복원한다.
  - **엔트리·리플렉션 새 창 보기**: 엔트리와 리플렉션을 읽기 전용 새 창(팝업)으로 연다. 등록·수정 모달에서는 작성 중 미리보기를 새 창으로 띄운다.
  - **복사 「보류 해석 제외」 모드**: 복사 split 드롭다운에 보류(PENDING) 리플렉션만 빼고 복사하는 항목을 추가했다(전체 → 보류 제외 → 본문만 3단계). 엔트리·챕터·검색·스레드 복사에 모두 적용된다.
  - **접힘 보류 항목의 TODO 표식**: 접힌 보류(PENDING) 엔트리·리플렉션의 요약 줄 맨 앞에 `TODO:`를 표시한다.
  - 접힌 리플렉션 헤더에 제목을 표시하고, 같은 대상 아래 리플렉션 형제 순번을 1..N으로 매긴다.
  - 스레드 목록을 소속 엔트리의 최신 날짜 기준으로 정렬한다.
- 개선 · 사용성
  - 일간 뷰에서 일자 등록 시 기본 날짜를 현재 보고 있는 날짜로 채운다.
  - 주간 미니 달력에서 날짜를 클릭하면 해당 일자 카드로 스크롤한다.
  - 완료(RESOLVED) 리플렉션 임베드에 일기와 같은 초록 음영을, 중요·참조 리플렉션에 해당 상태 음영을 표시한다.
- 버그 수정 · 정합성
  - 모달 안 TinyMCE 다이얼로그 입력이 막히던 문제와, 세션 만료 후 남던 모달 backdrop을 정리했다.
  - 복사 시 빈 문단을 보존하고 에디터 모달을 드래그로 옮길 수 있게 했으며, 혼합 인용·수평선 마크다운 감싸기를 교정했다.
  - 리플렉션 수정 시 열려 있는 스레드 상세 모달을 갱신하고, 스레드 상세를 다녀온 뒤 직전 화면으로 복귀하며, 엔트리 삭제 후 태그 클라우드를 갱신한다.
  - 리치에디터 종료(teardown) 시 빈 모델에 값을 쓰며 나던 크래시를 막았다.
- 성능 · 구조
  - 임베딩 기능 OFF에서는 전수 동기화·워커를 끄고 전수 조회의 N+1을 줄였다.
  - 저널 복사(엔트리·챕터·검색·스레드)의 리플렉션 이어붙임 포맷을 공통 유틸로 수렴했다.
  - 리플렉션 쓰기 가드를 대상 일자 소유(isOwnedBy) 기준으로 분리했다.
- 스키마 · 운영
  - 스레드 본문 이력 컬럼 마이그레이션(`V0.28.1`)을 추가했다. Flyway 자동 실행은 비활성 상태로, 스키마 변경은 `schema/migration/mariadb/`에 SQL 파일로 누적하고 적용 시점은 수동 통제한다.
  - local/dev p6spy 실행 SQL 로깅을 정리해 임베딩 전수 동기화 SQL을 DEBUG로 내렸다.
- 개발 규율 · 문서
  - spec 문서에서 향후 아이디어와 변경 이력을 걷어내 현재 계약만 남기고, 아이디어는 `docs/ideas/`로 분리했다. spec 등재 자격을 「계약 내부/외부」 축으로 명문화했다.
  - DB 스키마 변경 시 Flyway SQL 마이그레이션 파일 생성을 의무화하고, 시간봉인 순차분석 방법론 문서를 추가했다.

### 2026-08-07 | v0.26.0
- 신규 기능
  - 저널 "해석(interpretation)"을 독립 Entry 종류 **Reflection**(`JOURNAL_REFLECTION`)으로 승격했다.
    - Reflection 은 어느 챕터(일기/꿈/노트)에든 자유 배치한다. 소속 챕터는 hard-owned 이고, target(가리키는 대상 엔트리)은 표시위치만 결정하는 nullable 참조다.
    - 표시·검색·등록·수정·삭제를 모두 Entry 경로로 통합하고, 대상 엔트리 밑에 교차뷰(백링크)로 함께 보여준다.
    - 통합검색에 Reflection facet 과 target 유형(일기해석/꿈해석) 서브 facet 을 추가했다.
    - 리플렉션 이력(history) strategy 로 이력 조회·복원을 지원한다.
  - **스레드(Thread) 관계 구조**를 도입했다.
    - 엔트리 간 연결을 담는 스레드와 thread-relation(연관 스레드)까지 확장.
    - 엔트리에서 새 스레드 시작 시 접두사(말머리)를 수집한다.
    - 관련 스레드 출처를 filled source chips 로 표시하고, 스레드별 related 뷰를 합성한다.
  - **리플렉션 접힘/펼침**을 확정했다 — forceCollapsed string signal(Vue Boolean 캐스팅 우회)·신규 리플렉션 PENDING 기본 접힘·부모 펼침 신호의 중첩 전파·aside 기본접힘 토글.
  - **삭제 가드**: 리플렉션이 참조 중이거나 하위 엔트리가 남은 챕터/엔트리는 삭제를 차단한다.
