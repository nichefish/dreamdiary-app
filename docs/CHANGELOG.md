### 2026-09-13 | v0.30.0
- 신규 기능
  - **Keep**: 어디에 적어 둔 할 일이든 `/keep` 한곳에서 모아 보고, 검색·완료·보류·되돌리기로 관리한다. 저널 옆에는 아직 열린 것만 남는다.
  - **할 일**: 완료해도 지우지 않고 완료로 남기며, 보류했다가 다시 열 수 있다. 제목을 누르면 수정한다.
  - **일괄 태그**: 검색에서 여러 글에 태그를 한 번에 붙이고, 잘못 붙였으면 되돌린다.
  - 본문을 골라 우클릭하면 검색·복사할 수 있고, 일간 태그클라우드에 그날 스레드 요약이 보이며, 월 라벨로 날짜를 고를 수 있다.
  - 꿈 태그에 적힌 본문을 「상징 해석」으로 보여 준다.
- 개선·사용성
  - 일기 검색을 Shift 두 번으로 열고, 열리면 바로 입력한다.
  - 글 옆 동작을 단순화하고, 링크 복사는 복사 메뉴 안으로 옮겼다.
  - 사이드바 필터는 기본으로 접혀 할 일이 먼저 보인다.
- 버그 수정·정합성
  - 로그인 비밀번호 오류 메시지가 제대로 보이고, 빈 비밀번호는 보내지 않는다.
  - 일간·주간에서 글 고정(pin)·되돌리기가 다시 된다.
- 모바일
  - 모바일 앱을 일/주/월 **조회 전용**으로 정리했다.

### 2026-08-26 | v0.29.0
- 신규 기능
  - **스레드 본문 이력**: 스레드 본문의 변경 이력을 보고 이전 내용으로 복원한다.
  - **엔트리·리플렉션 새 창 보기**: 엔트리·리플렉션을 읽기 전용 새 창으로 열고, 작성 중인 내용도 새 창에서 미리 본다.
  - **복사 「보류 해석 제외」**: 복사할 때 보류 중인 해석만 제외할 수 있다(전체 / 보류 제외 / 본문만).
  - 접어 둔 보류 항목에는 `TODO:`를 표시해 처리할 내용이 남았음을 보여 준다.
- 개선·사용성
  - 일간 뷰에서 일자를 등록하면 현재 보고 있는 날짜를 기본으로 채운다.
  - 주간 미니 달력에서 날짜를 누르면 해당 일자 카드로 이동한다.
  - 스레드 목록을 소속 글의 최신 날짜 순으로 정렬한다.
  - 접힌 리플렉션에 제목과 형제 순번을 표시한다.
  - 완료·중요·참조 리플렉션을 상태별 음영으로 구분한다.
  - 에디터 모달을 드래그해 옮길 수 있다.
- 버그 수정·정합성
  - 모달 안 에디터 입력이 막히던 문제와 세션 만료 뒤 모달 배경이 남던 문제를 고쳤다.
  - 복사할 때 빈 문단을 보존하고, 혼합 인용·수평선의 마크다운 변환을 바로잡았다.
  - 리플렉션 수정 뒤 열린 스레드 상세가 바로 갱신되고, 엔트리 삭제 뒤 태그 클라우드가 갱신된다. 스레드 상세를 닫으면 직전 화면으로 돌아간다.
  - 에디터를 닫을 때 빈 내용 때문에 나던 크래시를 막았다.

### 2026-08-17 | v0.28.0
- 신규 기능
  - **저널 에디터 템플릿**: 미리 만든 템플릿을 에디터 드롭다운에서 본문에 삽입한다(관리자가 템플릿 관리).
  - **사용자별 기본 진입 화면**: 로그인 후 기본으로 열릴 저널 화면(일간/주간/월간)을 지정한다.
  - **복사·다운로드 「전체 / 본문만」**: 복사와 TXT 다운로드에서 주 버튼은 해석 포함, ▾는 본문만 담는다. 검색 결과는 날짜별로 그 날짜 글만 복사할 수 있다.
  - **엔트리 검색 강화**: 제목 전용 검색·정렬과 꿈 상태(악몽·환각) 검색을 더하고, 태그 메뉴에서 「이 태그로 검색」과 「검색에 추가」를 나눴다.
  - **엔트리 링크 복사**: 링크를 복사하면 그 엔트리로 이동한다. 원문 뷰에 「해당 글로 이동」을 더했다.
  - **인라인 댓글 수정·삭제**: 엔트리·리플렉션의 댓글을 목록에서 바로 고치고 지운다.
- 개선·사용성
  - **복사 계약**: 복사하면 화면에 그려진 결과가 아니라 입력한 원문(마크다운·문단 구조)이 그대로 담긴다. 순수 텍스트로 붙이면 입력한 그대로고, 앱 에디터에 되붙이면 원래대로 보인다.
  - 주간 필터를 미니 달력의 주 범위 하이라이트로 바꿨다.
  - 태그 자동완성에서 대소문자를 구분하지 않는다.
- 버그 수정·정합성
  - 완료 처리한 엔트리의 해석 상태가 어긋나던 것을 바로잡고, 상태를 바꾸면 접힘/펼침이 즉시 반영된다.
  - 「#」 재정렬이 챕터 순번을 어긋나게 하던 문제와, 부분 갱신 뒤 컨텍스트 메뉴가 안 먹던 문제를 고쳤다.
  - 스레드 상세를 다녀오면 직전 페이지로 복원되고, 스레드 소속·댓글 동작을 정리했다.
  - 긴 본문이 우측 액션을 밀던 레이아웃을 고쳤고, 관련 글 검색에서 해석을 제외했다.

### 2026-08-07 | v0.26.0
- 신규 기능
  - **해석(Reflection)을 독립적으로 다룬다**: 일기·꿈·노트 어느 챕터에든 자유롭게 두고, 대상 글 아래에 백링크로 함께 보이며, 통합검색에서 「해석/일기해석/꿈해석」으로 걸러 찾고, 변경 이력을 조회·복원한다.
  - **스레드 관계**: 스레드끼리 연관 지어 관련 스레드를 출처 칩으로 보여주고, 스레드별 관련 뷰를 제공한다. 새 스레드를 시작할 때 말머리를 붙인다.
  - **삭제 가드**: Reflection이 가리키고 있거나 하위 글이 남아 있는 챕터·글은 삭제하지 못하게 한다.
  - 해석을 `(( ))`로 감싸는 메뉴 동작을 더했다.
- 개선·사용성
  - 새 해석은 기본으로 접혀 보이고, 부모를 펼치면 함께 펼쳐진다.
  - 대상 글을 지워도 그 해석은 사라지지 않고 챕터에 남는다.
  - 요약 챕터를 일간 목록 맨 위에 고정하고, 챕터가 모두 정리되면 강조한다.
- 버그 수정·정합성
  - 해석 수정 권한이 항상 거부되던 문제를 고쳤다.

### 2026-08-03 | v0.25.0

  - 내 정보를 바꾸면 스레드 작성자 표시와 저널 스레드 검색 결과에 바로 반영된다.
