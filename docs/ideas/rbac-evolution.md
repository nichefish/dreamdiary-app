# RBAC 구조 확장 (아이디어)

> 상태: **아이디어 (계약 외부)** — 현재 Role·Group·Permission 판정과 메뉴 모드 계약을 변경하지 않는다.

## 메뉴 트리 단일화 후보

현재 메뉴는 `admin_yn`으로 사용자·관리자 모드 트리를 나누고 permission으로 세부 노출을 판정한다. 장기적으로 `admin_yn` 모드 구분을 없애고 permission만으로 하나의 트리를 구성할지는 별도 검토 대상이다.

열린 질문:

- 사용자·관리자 모드 전환 UX를 무엇으로 대체할지
- URL 없는 폴더 노드와 동적 게시판 트리를 어떤 규칙으로 묶을지
- 기존 메뉴 캐시 키와 관리자 진입 권한을 어떻게 수렴할지
