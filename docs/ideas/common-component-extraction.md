# Vue 공통 컴포넌트 추출 (아이디어)

> 상태: **아이디어 (계약 외부)** — 현재 각 소비 컴포넌트의 인라인 구현을 공통 Vue 컴포넌트로 추출하는 리팩터링은 합의된 계약이 아니다.

## 추출 후보

| 현재 인라인 동작 | 공통화 후보 |
|---|---|
| 목록 댓글 수와 댓글 모달 진입 | 목록 댓글 컴포넌트 |
| 목록 상세 모달 진입 버튼 | 목록 상세 버튼 컴포넌트 |
| 목록 태그 렌더링 | `TagList.vue` |
| 표준 모달 헤더 | `ModalHeader.vue` |
| 이전 모달 복귀 포함 헤더 | `ModalHeaderWithBack.vue` |
| 저장 버튼과 진행 표시 | `ModalBtnSave.vue` |

공통화 여부는 실제 중복 수, props·이벤트 계약의 공통분모, 기존 DOM·CSS·모달 스택 동작을 그대로 보존할 수 있는지를 확인한 뒤 결정한다.
