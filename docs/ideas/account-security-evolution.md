# 계정 보안 기능 확장 (아이디어)

> 상태: **아이디어 (계약 외부)** — 계정 이메일 변경 기능은 현재 프로필·보안 화면 계약이 아니다.

## 이메일 변경 후보

계정 이메일은 OAuth2 사용자 식별에 사용되므로 일반 프로필 저장과 분리된 보안 흐름이 필요하다. 후보 흐름은 현재 비밀번호 확인, 새 이메일 중복 검사, 새 주소 소유 검증과 인증 상태 재발급을 하나의 변경 절차로 묶는다.

결정이 필요한 항목은 OAuth2 공급자 식별자와 이메일의 분리 여부, 검증 전 임시 상태, 기존 세션 만료 범위, 실패·재시도·복구 정책이다.
