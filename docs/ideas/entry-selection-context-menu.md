# 엔트리 본문 선택 우클릭 컨텍스트 메뉴 (아이디어)

> 상태: **아이디어 (계약 외부)** — 아직 구현·합의 대상이 아니다. 합의되면 그때 spec + 구현으로 넘긴다. 이 문서는 발전 방향 스케치이지 계약이 아니다.

## 한 줄
엔트리·리플렉션 본문에서 텍스트를 드래그(선택)한 채 우클릭하면, 브라우저 네이티브 메뉴 대신 저널 맥락 액션을 담은 커스텀 메뉴를 띄우면 어떨까.

## 배경 / 동기
- 지금은 본문에서 선택 후 우클릭하면 브라우저 기본 메뉴(복사·인쇄·Google/Gemini 검색 등)만 뜬다.
- 저널 맥락에서 더 쓸모 있는 건 "이 조각을 저널 전체에서 검색" 같은 앱 전용 동작.

## 러프 스케치 (확정 아님)
- 선택(드래그)이 있을 때만 가로채고, 선택이 없으면 네이티브 메뉴를 그대로 둔다.
- 후보 항목: 복사 / 검색.
- 검색은 선택 텍스트를 키워드로, 타입은 일기/꿈 맥락에서 파생하는 방향.

## 열린 질문
- **노트(JOURNAL_NOTE) 도메인** 검색 정책 — 노트 자체를 어떻게 다룰지 미정이라 함께 재논의 필요.
- 실제로 만들지 여부 자체가 미정.

## 관련
- 검색 진입 단축키(Shift 두 번) 아이디어와 짝지어 생각해볼 수 있음.
