# 꿈 태그 상징 해석 (아이디어)

> 상태: **아이디어 (계약 외부)** — 꿈 태그에 별도 해석을 축적하는 기능은 현재 저널·꿈·태그 계약이 아니다.

## 후보 방향

꿈 태그에 해석을 연결해 반복 상징의 사례와 변주를 누적하는 방안이다. 개별 꿈의 Reflection을 대체하지 않고, 여러 기록에서 반복되는 상징을 별도 기준면으로 다루는 것을 전제로 한다.

## 열린 질문

- 해석의 소유 단위가 태그 자체인지 사용자별 태그 프로필인지
- 한 태그에 하나의 현재 해석을 둘지 변경 이력을 축적할지
- 개별 꿈 Reflection과 태그 상징 해석이 충돌할 때 어떤 정보를 우선 표시할지
- 검색·RAG·연간 결산이 이 해석을 소비할지
