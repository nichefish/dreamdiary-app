# 저널 검색 진입 키보드 단축키 (아이디어)

> 상태: **아이디어 (계약 외부)** — 아직 구현·합의 대상이 아니다. 합의되면 그때 spec + 구현으로 넘긴다. 이 문서는 발전 방향 스케치이지 계약이 아니다.

## 한 줄
저널 전체검색(엔트리 검색 팝업)을 키보드 단축키로 바로 띄우면 편하지 않을까.

## 배경 / 동기
- 지금은 툴바 "전체검색" 버튼으로만 검색 팝업을 연다.
- IntelliJ의 "Search Everywhere"(Shift 두 번)처럼 손버릇으로 바로 진입하면 빠르다.

## 러프 스케치 (확정 아님)
- 후보 키: **Shift 두 번**(IntelliJ 검색 손버릇과 일치, 브라우저 예약키와 충돌 없음). Ctrl+K도 웹 표준 후보.
- Ctrl+R / Ctrl+Shift+R / Ctrl+F는 브라우저 새로고침·찾기와 충돌하므로 피한다.
- 입력 필드·에디터에 포커스가 있을 때는 오발동을 피하는 가드가 필요.

## 열린 질문
- Shift 두 번의 오발동(타이핑 중) 방지 범위.
- 실제로 만들지 여부 자체가 미정.

## 관련
- 본문 선택 우클릭 컨텍스트 메뉴 아이디어(`entry-selection-context-menu.md`)의 "검색"과 진입점을 공유할 수 있음.
