# AI 채팅 확장 (아이디어)

> 상태: **아이디어 (계약 외부)** — 아래 항목은 현재 채팅 동작 계약이나 구현 계획이 아니다. 개별 항목이 합의되면 관련 spec에 먼저 반영한다.

## 역할 확장

- 도구 호출을 도입할 경우 `TOOL` 역할로 결과 메시지를 구분하는 방안을 검토한다.

## 장기 대화 기억

최근 N개 메시지 기억 앞에 오래된 대화 요약을 결합하는 구조를 후보로 둔다.

```text
system prompt
+ 오래된 대화 요약
+ 최근 N개 raw 메시지
+ 현재 사용자 질문
```

- 세션 요약과 마지막 요약 위치를 저장하는 필드가 필요할 수 있다.
- 요약 생성 시점, 재요약 조건, 원문 보존 경계는 열린 질문이다.

## UI 후보

- 응답 재생성
- 메시지 복사
- 대화 검색
- 세션 보관
- 사용자 모델 선택
- 저널 엔트리 외 TODO·일정 등 데이터 참조 범위 확장

## 소유권 후보

- 현재 `chat`이 소유하는 `rag_top_k` 등 Admin RAG 설정을 채팅 채널과 분리된 `ai` 설정으로 옮길지 검토한다.
