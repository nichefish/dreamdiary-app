# 모바일 앱 v0.1 화면 계약

> 이 문서는 모바일 앱의 화면·사용자 흐름 계약을 정의한다.
> 웹(Vue) 저널 화면 계약은 `docs/migration/journal/`에서 독립적으로 관리한다.
> 모바일 앱은 백엔드가 제공하는 저널 데이터·인증·검색 의미를 공유하지만 웹의 DOM·레이아웃·조작 흐름을 상속하지 않는다.

---

## 1. 제품 목적

모바일 앱 v0.1은 로그인 사용자가 자신의 저널 기록을 날짜 또는 검색 조건으로 찾아 읽는 **조회 전용 리더**다.

성공 기준은 다음과 같다.

1. 선택한 일·주·월의 기록을 조회할 수 있다.
2. 키워드 또는 태그로 기록을 찾을 수 있다.
3. 조회·검색 결과에서 기록의 상세 본문을 읽을 수 있다.
4. 저널 데이터의 생성·수정·삭제 없이 위 흐름을 완료할 수 있다.

---

## 2. 계약 경계와 SSOT

| 자산 | 소유 계약 |
|---|---|
| `docs/migration/mobile/screen-spec.md` | 모바일 화면, 탐색 흐름, 조회 전용 경계 |
| `docs/migration/journal/screen-spec.md` | 웹 저널 화면과 웹 전용 레이아웃 |
| `docs/migration/journal/interaction-spec.md` | 웹 저널 인터랙션 |
| 백엔드 저널·인증 API | 사용자 소유권, 날짜 범위, 검색 조건, 응답 데이터 의미 |

모바일은 서버 응답을 표시·탐색하는 클라이언트다. 날짜 범위, 태그 종류, 엔트리 유형과 검색 결과의 의미를 클라이언트에서 별도로 재해석하거나 임시 데이터로 보정하지 않는다.

조회 전용 경계는 저널 데이터에 적용한다. 로그인, 인증 상태 확인, 토큰 갱신, 로그아웃은 앱 접근을 위한 인증 흐름이므로 저널 쓰기로 취급하지 않는다.

## 3. v0.1 구현 현황

현황 표기는 합의된 v0.1 계약에 대해서만 사용한다.

- ✓: 계약 충족
- ⚠: 일부 충족
- ❌: 계약 미충족

| 계약 | 현황 | 확인 근거 |
|---|:---:|---|
| 인증 후 조회 화면 진입 | ✓ | `AuthContext`와 `LoginScreen`이 인증 상태에 따라 앱 화면을 전환한다. |
| 일별 조회 | ✓ | `TodayScreen`이 선택한 하루의 저널 일자를 조회한다. |
| 주별 조회 | ✓ | `TodayScreen`의 일/주 토글에서 주 모드(`JournalWeeklyView`)가 월요일 시작 주의 저널 일자를 날짜 순서로 조회하고 상세 진입을 제공한다. |
| 월별 조회 | ✓ | `TodayScreen`의 일/주/월 토글에서 월 모드(`JournalMonthlyView`)가 기준 연·월의 저널 일자·엔트리를 날짜 순서 연속 목록(`JournalDaySection`)으로 표시하고 상세 진입을 제공한다. |
| 키워드 검색 | ✓ | `SearchScreen`이 키워드 엔트리 검색과 상세 진입을 제공한다. |
| 태그 검색 | ✓ | `TagExploreScreen`이 일자·일기·꿈 태그 탐색과 결과 진입을 제공한다. |
| 상세 읽기 | ✓ | `EntryDetailScreen`이 선택한 엔트리의 전체 본문을 표시한다. |
| 저널 조회 전용 | ✓ | 모바일 화면과 API 파사드가 저널 조회 요청만 수행하며, 생성·수정·삭제 화면과 해당 API 호출이 없다. |

## 4. 화면 구조

v0.1은 다음 세 가지 논리 화면을 제공한다.

```text
인증
  └─ 날짜 조회 ─┐
                ├─ 상세 읽기
      검색 ─────┘
```

이 화면 구조는 논리적 역할을 나타내며, 네이티브 내비게이션은 위 이동 흐름을 보존한다.

### 4.1 날짜 조회

날짜 조회 화면은 일별·주별·월별 보기와 기준 날짜 또는 기간 선택을 제공한다. 일·주·월 보기는 하나의 화면에서 토글로 전환한다.

각 보기는 서버가 반환한 날짜별 저널 구조를 유지하며, 사용자는 표시된 엔트리에서 상세 읽기로 진입할 수 있다.

### 4.2 검색

검색 화면은 키워드 검색과 태그 검색 두 축을 제공한다.

#### 4.2.1 키워드 검색

- 입력한 키워드로 서버의 저널 엔트리를 검색한다. 키워드가 비어 있으면 검색을 실행하지 않는다.
- 유형 필터(전체·꿈·일기)로 검색 대상을 좁힌다. 이미 검색한 뒤 필터를 바꾸면 현재 키워드로 다시 검색한다.
- 검색 실행 전 idle 상태와 결과 0건 상태를 구분한다.
- 결과 항목은 유형·기준 날짜·제목·본문 미리보기를 표시하고, 선택하면 상세 읽기로 이어진다.

#### 4.2.2 태그 검색

- 기준 연·월의 태그를 일자·일기·꿈 세 구획으로 나누어 제공하고, 기준 연·월을 이전/다음 달로 이동한다.
- 각 태그는 이름과 해당 태그의 기록 수를 함께 표시한다.
- 일자 태그를 선택하면 그 태그가 붙은 저널 일자 목록을 조회한다. 태그가 활성인 연도 범위 안에서 조회 연도를 이동하며, 일자 항목은 날짜 조회로 이어진다.
- 일기·꿈 태그를 선택하면 그 태그가 붙은 엔트리 목록을 조회하고, 엔트리를 선택하면 상세 읽기로 이어진다.

#### 4.2.3 검색 결과 상태

- 조회 중, 결과 0건, 조회 실패를 서로 다른 상태로 표시한다.
- 조회 실패를 빈 결과로 보정하지 않으며, 재검색 또는 재시도로 다시 조회할 수 있다.

### 4.3 상세 읽기

상세 화면은 선택한 엔트리의 서버 확정 데이터를 표시한다.

- 기준 날짜
- 엔트리 유형
- 제목
- 본문

응답에 값이 없는 선택 필드는 빈 UI를 억지로 채우지 않는다. 본문은 사용자가 기록 내용을 읽을 수 있도록 화면 너비 안에서 스크롤 가능한 형태로 표시한다.

## 5. 날짜 조회 계약

### 5.1 일별 조회

- 기준일 하루에 속한 저널 일자와 엔트리를 표시한다.
- 챕터와 엔트리의 서버 정렬 순서를 유지한다.
- 선택한 엔트리는 상세 읽기로 이어진다.

### 5.2 주별 조회

- 한 주는 월요일부터 일요일까지의 7일이다.
- 기준일이 속한 주의 저널 일자와 엔트리를 날짜 순서로 표시한다.
- 기록이 없는 날짜와 조회 실패 상태를 구분한다.
- 선택한 엔트리는 상세 읽기로 이어진다.

### 5.3 월별 조회

- 기준 연·월에 속한 저널 일자와 엔트리를 날짜 순서 연속 목록으로 표시한다.
- 기준 연·월을 이전/다음 달로 이동하며 조회하고, 미래 달로는 이동하지 않는다.
- 기록이 없는 달과 조회 실패 상태를 구분한다.
- 선택한 엔트리는 상세 읽기로 이어진다.

---

## 6. 조회 전용 계약

모바일 v0.1은 저널 데이터에 대해 읽기 요청만 수행한다.

- 날짜 조회, 검색, 태그 조회와 상세 조회에서 저널 생성·수정·삭제 API를 호출하지 않는다.
- 날짜·검색 결과·상세 화면에 저널 생성·수정·삭제 조작을 노출하지 않는다.
- 조회 오류를 해결하기 위해 저널 데이터를 생성하거나 클라이언트 임시 항목을 주입하지 않는다.
- 서버가 반환한 데이터와 오류를 앱 상태의 기준으로 사용한다.

---

## 7. 공통 화면 상태

모든 조회 화면은 다음 상태를 구분한다.

| 상태 | 계약 |
|---|---|
| 초기 조회 중 | 진행 상태를 표시하고 빈 결과로 단정하지 않는다. |
| 조회 성공 | 현재 조건과 일치하는 서버 확정 데이터를 표시한다. |
| 결과 없음 | 조회가 성공했고 결과가 없음을 안내한다. |
| 조회 실패 | 오류 안내와 재시도 수단을 제공하며 실패를 0건으로 표시하지 않는다. |
| 인증 만료 | 저장된 인증 정보를 정리하고 로그인 화면으로 전환한다. |

이전 성공 데이터를 유지하는 경우 현재 조회 조건의 데이터인지 구분할 수 있어야 한다. 다른 날짜·기간·검색 조건의 결과를 현재 결과처럼 표시하지 않는다.

## 8. v0.1 완료 조건

다음 조건을 모두 만족하면 모바일 앱 v0.1 계약을 충족한다.

- §3의 모든 계약이 ✓ 상태다.
- 일별·주별·월별 조회 결과에서 상세 본문을 읽을 수 있다.
- 키워드·태그 검색 결과에서 상세 본문을 읽을 수 있다.
- 앱의 사용자 흐름과 저널 API 호출 경로에서 생성·수정·삭제 기능이 노출되지 않는다.
- 인증, 로딩, 빈 결과, 오류와 재시도 흐름이 실기기에서 구분되어 동작한다.
- 모바일 TypeScript 타입 검사와 저장소 인코딩 검사를 통과한다.
